# v1.6.1

修复 Windows 启动脚本可能报错 9009、无法进入飞书首次设置的问题，并修复安装目录包含括号时的首次设置提示。启动失败时正确返回错误码，避免错误被暂停提示掩盖。

本机首次设置通过单一向导连续完成凭证录入、绑定、测试与启用，减少反复切换脚本。修复独立安装和整合安装的运行时路径识别。新装说明加入功能中心菜单、事件与卡片回调配置，并在完成前检查菜单和卡片是否可用。

## 已安装 v1.6.0

下载本版本的 `upgrade-from-v1.x.zip`，解压到旧安装目录之外，运行**新包**根目录的 `快捷升级.cmd`，选择原安装目录。不要运行旧包中的升级入口，也不要仅替换 EXE。升级保留配置、绑定与用户数据；同名旧插件保存在 `.state/plugin-backups`，新包的首次设置入口生效。

此前首次设置未完成的用户，升级后重新打开百宝箱并进入飞书首次设置；已完成配置和绑定的用户直接继续使用，不必重新配对。安装路径可包含中文、空格、括号和 `&`；避免使用 `%PATH%` 等环境变量形式的目录名。

新用户下载 `full.zip`，按包内安装指南操作。v1.5 用户仍可使用本版本升级包；更早版本的迁移要求见 [升级说明](../UPGRADE.md)。本次修复不改变飞书权限、数据库结构或业务功能。
