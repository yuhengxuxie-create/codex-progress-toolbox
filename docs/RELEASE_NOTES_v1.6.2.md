# v1.6.2

本版本改进 Skills 和斜杠指令浏览、会话名称与模型信息显示，并为更新检查增加限流等待提示和官方手动下载入口。

- 检查更新遇到 GitHub 限流时显示等待提示，并按服务要求暂停请求；必要时尝试官方发布清单。新增“打开官方发布页”按钮，方便手动下载升级包。
- 功能中心的 Skills 直接展示个人及全局已启用技能，可翻页和刷新，无需先选会话；浏览不会执行技能。项目专属技能仍需明确关联对应任务。
- 斜杠指令入口直接显示指令用途、支持情况和使用方法。
- 修复客户端日志轮转后可能无法读取 Skills 的问题；遇到加载失败时给出明确提示，不把失败当成空列表。
- 更准确地保留客户端提供的会话名称，减少已有名称被替换为历史会话占位名的情况。
- 兼容当前客户端模型信息结构，修复模型和推理强度可能显示为空的问题。官方拒绝操作时显示安全的错误类别和数字代码。

模型设置仍受官方接口与账号能力限制；此修复不保证被拒绝的模型切换会成功。缺少可靠名称的任务仍使用占位名，不根据正文猜名。

## 升级与安装

已有 v1.5.0、v1.6.0 或 v1.6.1 用户下载本版本的 `upgrade-from-v1.x.zip`，解压到原安装目录之外，运行新包中的“快捷升级.cmd”，选择原安装目录。升级保留配置、绑定与用户数据，无需重新配置飞书权限或重新配对。请勿只替换 EXE。

旧版检查更新出现 `403 (rate limit exceeded)` 时，可直接从本发布页下载升级包。新版会按服务要求等待，必要时读取官方发布清单；仍可用“打开官方发布页”手动下载。

新用户选择 `full.zip`，按包内 AGENTS.md 完成安装和统一首次设置。更早版本迁移、备份与回滚见 [升级说明](../UPGRADE.md)。
