# 飞书自定义机器人配置

本项目只需要“群自定义机器人”的 Webhook，不需要创建企业自建应用，不需要
App ID、App Secret、事件订阅、权限审批或应用发布。

飞书官方入口：
[自定义机器人使用指南](https://open.feishu.cn/document/client-docs/bot-v3/add-custom-bot)。

## 1. 选择目标群

建议新建一个仅自己或可信成员可见的群，用于接收 Codex 进度。通知可能包含
对话标题和 50 字内摘要，群成员应符合你的信息访问边界。

## 2. 添加自定义机器人

飞书客户端界面可能随版本变化，通常路径为：

1. 打开目标群；
2. 打开群设置；
3. 进入“群机器人”或“机器人”；
4. 选择“添加机器人”；
5. 选择“自定义机器人”；
6. 填写名称、描述和可选头像；
7. 进入安全设置。

如果看不到“自定义机器人”，通常是群类型、组织策略或管理员权限限制。此时
需要群管理员或组织管理员开放能力，项目脚本无法绕过。

## 3. 配置安全策略

飞书自定义机器人可使用关键词、IP 白名单和签名校验，策略可以组合。

- 签名校验：推荐。创建后保存签名密钥，本项目会为每条消息生成
  `timestamp` 和 HMAC-SHA256 `sign`。
- 关键词：可选。项目四行文本固定包含 `对话名称`，可将它设为关键词。
- IP 白名单：只适合发送电脑有稳定公网出口 IP 的场景。家庭宽带或移动网络
  公网 IP 变化时可能导致消息被拒绝。

不要为了排障长期关闭所有安全策略。Webhook 本身就是发送凭据；任何人获得它
都可能向该群发送消息。

## 4. 保存凭据

完成机器人创建后会得到：

- Webhook URL，形如
  `https://open.feishu.cn/open-apis/bot/v2/hook/替换为机器人ID`；
- 可选的签名密钥。

不要把真实值粘贴到 Codex 聊天、README、Issue、截图、配置示例或 Git 提交。

## 5. 在本机无回显配置

先运行安装器，再运行：

```powershell
.\scripts\configure-feishu.ps1
```

向导会检查 HTTPS 主机与自定义机器人路径，并用无回显输入读取真实值。它会：

1. 将 Webhook 写入 Windows User 级 `PROGRESS_WEBHOOK_URL`；
2. 将可选签名密钥写入 `PROGRESS_FEISHU_SECRET`；
3. 在 `config.local.json` 中只保存环境变量占位符；
4. 修改已有配置前创建时间戳备份；
5. 不把凭据输出到终端。

没有开启签名校验时，在密钥提示处直接回车即可。
如果要明确清除先前保存的签名密钥，也可以运行
`.\scripts\configure-feishu.ps1 -NoSigning`，Webhook 仍会用无回显方式重新输入。

`-WebhookUrl` 和 `-SigningSecret` 参数仅用于受控自动化；参数值可能进入终端历史
或进程命令行，日常配置不要使用它们。

## 6. 验证

```powershell
.\scripts\validate.ps1
.\scripts\send-test.ps1 -DryRun
```

确认预览后，明确同意外发再运行：

```powershell
.\scripts\send-test.ps1
```

消息到达后，完全退出并重启 Codex，再完成一个已选中对话的正常轮次。

## 常见飞书错误

| 现象/错误码 | 常见原因 | 处理 |
| --- | --- | --- |
| `19001` | Webhook 无效或机器人已删除 | 重新复制或重新创建机器人 |
| `19021` | 签名密钥不匹配或时间戳超窗 | 重新运行配置向导，并校准系统时间 |
| `19022` | 发送端公网 IP 不在白名单 | 更新白名单或改用其他安全策略 |
| `19024` | 消息不含配置的关键词 | 将关键词设为 `对话名称` 或调整规则 |
| HTTP 成功但项目报错 | 飞书业务响应拒绝 | 根据脱敏日志核对机器人安全设置 |

项目不会把飞书返回的远端消息原文写进公开异常，以免回显请求细节。

## 凭据泄露后的处理

1. 立即在飞书中删除或重置该自定义机器人，使旧 Webhook 失效；
2. 重新创建机器人并生成新签名密钥；
3. 重新运行 `configure-feishu.ps1`；
4. 如凭据进入 Git 历史，仅删除当前文件不够，还需要清理历史并轮换凭据；
5. 检查群内是否出现非预期消息。
