# 日常使用

## 飞书命令

- “查看项目”或“查看个人会话”：取得分页列表。
- 引用列表回复显示的编号：选择对应项目或会话，编号与被引用的 message_id 绑定。
- “新建项目”“新建个人会话”：按机器人后续提示引用回复。
- 引用会话概览直接发新要求：继续原 Codex 会话。
- 同一富文本发送图片与文字；纯图片可暂存 10 分钟，再补一条文字说明。
- “查询剩余额度”：显示 Codex 每周可用百分比和剩余重置卡数量。
- “使用说明”：发送六张课堂图片；“文字版使用说明”发送文字说明。

待审批消息中，引用回复“允许一次”或“拒绝”。只有请求自带可复用规则且通过 `codex execpolicy check` 时才显示“允许类似操作”。

## 百宝箱

项目监测表显示：会话名称、项目/个人归属、来源、最后活动时间、剩余有效时间、完整任务 ID。手动项永久保留；自动项连续 24 小时无活动后到期。明确移除自动项会留下抑制记录，避免马上恢复。

“监测设置”通过 `monitor-settings` 热切换自动发现。关闭不会删除已有 auto 项，它们按原到期时间退出；manual 项不受影响。

## 服务状态

在 TreasureChest 中使用启动、停止和状态。命令行只读检查可运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File '<安装目录>\components\codex-feishu\scripts\status.ps1' -ToolsRoot '<安装目录>\components'
```

不要手工编辑状态库或用文本编辑器改写监测注册表。
