# 飞书机器人文字版使用说明

说明修订日期：2026-09-09

重要提醒：

从飞书聊天底部点击“功能中心”，再点击需要的功能。也可以直接发送“.功能中心”、“.查询会话”、“.新建个人会话”、“.指令使用”等入口名称。

直接发送普通文字入口时，ASCII 半角句点“.”必须是第一个字符，并且整条消息只能有一行；旧的无点精确入口只会提示新的写法，不会直接发任务。未知入口、重复句点、句点命令末尾带空格或多行句点命令都不会发任务。句中句点、开头空格或全角句点“。”不会识别为机器人入口，会按普通文字处理，仍需引用目标任务；“/”和“$”指令继续按各自的原写法使用。暂存图片期间，打开功能中心或发送未知点命令不会消费暂存图片。

普通对话需要告诉机器人你要继续哪个任务：长按目标任务的概览、完成通知或该任务发来的图片或文件，点击“回复”，确认输入框上方引用的是正确任务，再输入要求。只打开列表、看过某个任务，不代表之后随便发一句话都会进入它。

卡片按钮可以直接点击。使用编号或文字表单操作时，一定要引用回复对应的机器人消息，避免选错列表。新建个人或项目会话时，按提示选好目标后，直接回复新建提示并输入要做的事即可。旧模板仍可使用；若使用模板，字段名称不要改。

查看会话：

1. 点击“功能中心”里的“查询会话”，选择“项目会话”“个人会话”或“模糊搜索”。
2. 项目会话先选项目，再点任务名称；个人会话直接点任务名称。列表可用上一页、下一页翻页。
3. 打开概览后，核对任务名称和最后一轮结果，再选择继续对话、添加或移除监测、查看原文、归档会话或指令使用。

也可以通过发送文字来进行功能的使用：直接发送“.查询项目列表”或“.查询个人会话”。引用项目列表发送“展开A01”，引用任务列表发送“选定a01”或“选定p01”；翻页可引用当前列表发送“第2页”。编号以当次列表为准。

模糊搜索：

忘了任务放在哪里时，点“功能中心”中的“搜索会话”，或从查询卡片点“模糊搜索”。填写“会话名称”“会话描述”“最后活动时间”，再点“开始搜索”。只记得部分信息也可以，三项都允许留空；全部留空会列出最近的任务。

时间可以写“今天”“昨天”“本周”“最近7天”或具体日期。结果不止一个时，按提示选择目标；也可以通过发送文字来进行功能的使用：引用候选列表发送“选择1”或“翻页”。如果机器人建议扩大搜索范围，确认需要后，再引用提示发送“确认增加搜索范围”。

新建对话：

新建个人会话：在“功能中心”点“新建个人会话”。长按收到的新建提示，点击“回复”，直接写清要做什么并发送，不必复制模板或添加字段名。创建完成后，核对新任务名称，再回复它继续操作。

已有项目里开新任务：在“功能中心”点“项目新会话”，按提示选择项目和运行方式，再引用最终的新建提示，直接发送任务要求。需要选择时可按提示回复项目编号，以及“本地”或“工作树”，无需复制整段表单。也可以直接发送“.项目新会话”或“/project”进入。

新建项目：点“新建项目”，按收到的表单填写项目名称、是否需要第一段会话及首轮要求。表单要求“是”或“否”时，按原样填写。

继续已有对话：

找到任务后，长按并回复它的概览或完成通知，直接发送新的要求，就会继续同一个任务。也可以点概览上的“继续对话”，在独立输入卡填写内容，再点“发送到此会话”。

你也可以直接回复自己之前已经关联到该任务的消息，例如收到“已安全保存”或“已排队”回执的那条要求，不必回找机器人的总结。后续再回复自己的续聊消息，也会继续同一任务；尚在排队的要求按该任务顺序处理。只有目标已可靠确定并保存的消息才有效，机器人不会根据当前打开的任务猜测。

同一条仍有效的任务消息可以多次引用。任务正在运行时，新要求会追加给正在处理的任务；任务已结束时，会在该任务中开启新一轮。任务自己生成的图片也可以引用，用来提出修改要求。

“已排队”表示机器人正在等待把内容交给Codex；“已追加”才表示已交给任务。暂时排队时不要重复发送同一要求。若提示消息过期或找不到任务，请重新查询并回复新的概览。

发送图片：

推荐把图片和文字放在同一条消息中，并引用目标任务的概览或通知再发送。续聊输入卡用于填文字；发图片时使用飞书聊天里的图片功能。

如果手机不能同时发送图文，可以先引用目标消息只发图片。收到“图片已暂存”后，直接发送一条普通文字说明，不要再引用其他消息。暂存有效期为10分钟，最多5张。

只想把暂存图片交给任务，发送“.发送”；放弃这批暂存，发送“.取消”。这里使用英文半角句点。

指令使用：

在目标任务概览上点“指令使用”，或引用目标概览回复“指令使用”，可以打开它的工具入口。查看任务后要操作哪个任务，就回复哪一条任务消息，不要引用无关通知。

点“/ 指令列表”查看当前支持的命令。也可以直接发送“.查看指令列表”、“.斜杠指令”或“/commands”；下一页可按卡片按钮，文字方式为“/commands page 2”。新增支持的命令以重新打开后的列表为准。

需要任务的指令首次使用时，会让你选择目标。选好后，可直接发送“.Skills”或原生“/goal”“/plan 任务要求”“/skills”等已支持的指令，不必每次引用；也可以引用目标任务的概览发送指令，明确指定本次对象。普通聊天正文仍按前文的回复方式续聊。

Skills每次打开都会刷新，提交使用前也会再检查。新增或启用Skill后，重新打开Skills查看；可按卡片提示使用，或发送“$技能名 请求”。

直接发指令时，让“/”或“$”位于第一个字符，并保持单行。未知或不完整的指令会收到提示，请按指令列表补全，不要凭空猜按钮或写法。

想核对当前绑定任务，发送“.查看当前会话”；需要改变或清除绑定时，发送“.切换当前会话”或“.清除当前会话”。

管理进度监测：

在任务概览点“添加监测”或“移除监测”。也可以在“功能中心”的“进度监测”区域点“查看监测”“添加监测”“移除监测”或“监测设置”，按卡片提示操作。

也可以通过发送文字来进行功能的使用：发送“.查询监测列表”查看；引用目标概览发送“添加监测”或“移除监测”。使用列表编号时，可引用项目任务列表发送“添加监测a01”、个人任务列表发送“添加监测p01”，或引用监测列表发送“移除m01”。

开启自动监测时，新建或最近活跃的顶层任务会自动加入，连续24小时没有活动后自动到期。手动添加的监测持续有效，直到移除。明确移除后，机器人不会擅自恢复。

会收到什么通知：

直接提问有明确答案、你要求的方案已经可供审阅、出现影响使用或决定的重要变化、需要你操作，以及当前委托的任务完成时，机器人会发送简短通知。长期项目尚未结束，也不会挡住一个独立问题的答案。

内部计划、调试、常规测试、等待内部结果和没有新结论的中间进度保持安静。同一事实已经成功通知且没有变化时不会重复发送；你主动再次提问，仍会得到答复。通知会保留失败、未完成项和不确定性，不会为了发消息编造确认步骤。

本轮新生成的图片会以图片形式独立发送，文字无需通知时仍会发送图片；图片和总结可能先后到达。回复总结或这些任务图片，都能继续对应任务。使用说明图片用于教学，不是某个工作任务的续聊入口。

对话成果文件自动发送：

本轮最终答复明确交付的本地文件会自动发送到飞书，包括文档、表格、幻灯片、压缩包、音视频、代码及无扩展名文件。文件名保持原样，可以直接回复收到的文件继续原任务。正文中的源代码行号引用、代码示例、普通网页来源链接不会当作附件。

文件与文字总结分别处理：文字无需通知时仍可收到成果文件；总结和文件可能先后到达，单个文件失败不影响其他文件。附件通常按交付顺序处理；前件等待重试时，后面的文件可能先到。程序在后台保存交付副本；保存前原文件发生变化或被删除会明确提示，保存后原文件修改不影响已排队副本。首次启用不会批量补发历史任务文件。

飞书普通文件须非空且不超过30MB；无法对应到本机文件的远程或sandbox链接不能直接发送，程序会说明可验证范围，不猜测本机映射。超限、文件缺失或平台明确拒绝会收到说明。平台结果未知时暂停该文件，避免重复发送；不会擅自改传网盘。待发送空间满时会说明原因并等待空间释放；已成功发送的副本自动回收，结果未知的副本保留。

遇到权限申请时，按该条审批通知操作。文字方式为引用审批通知发送“A”或“允许一次”，拒绝则发“D”或“拒绝”。只有通知中出现相应选项时，才可以用“S”或“允许类似操作”。

Codex额度重置预警：

在“功能中心”的进度监测区域点“预警状态”或“最近预警”；也可直接发送“.重置预警状态”或“.最近预警”。前者查看监测来源是否可用，后者回看已触发的提醒。

预警可能是未来重置的预告，也可能是官方宣布重置或重置券可用。请查看公告里的适用计划、资格条件和时间，再核对自己的额度或重置券。收到提醒不代表你的个人额度已重置，机器人也不会替你使用重置券。

来源显示“部分可用”或受限时，表示信息可能不完整；没有提醒也不能证明一定没有重置。已过期的记录可供回看，不代表现在仍能领取或使用。

电脑端百宝箱的“预警记录”可查看历史和未读记录，需要时手动标为已读。它的提醒不必等待飞书发送成功；系统是否显示气泡，也会受电脑通知设置影响。

查看原文与归档：

查询概览中的“查看原文”（文字方式“.原文”）查看的是那次查询所对应的最后一轮完整答复，同一份查询结果只能成功使用一次。想看新的结果，请重新查询。

回复任务完成总结并单独发送“.原文”，可回看该次完成轮的完整答复；可以再次请求。它不会把后续通知改成全文，也不会向任务追加新要求。

两种原文入口都要对准对应消息；“.原文”必须单独发送，不附图片。如果原答复已经不可读取，机器人会说明情况，不会用别的轮次代替。

需要归档时，在任务概览点“归档会话”并确认，或引用概览发送“.归档”。归档会改变任务状态，请先核对任务名称。如果提示结果无法确认，先在Codex中核对，不要反复提交。查看原文和归档相互独立。

机器人停止与远程启动：

业务服务异常停止时，通信守护会尽可能通知你。只要电脑仍在运行、网络可用且守护正常，你可以直接发送完整的“.启动飞书机器人”，无需引用任何消息。该指令只接受原来已绑定用户的私聊；不要加空格、图片或其他文字。

从电脑、命令行、自动启动或飞书启动后，只有业务与通信都真正就绪才会发送一条成功通知；重复点击启动不会重复创建业务。正常停止会保留远程救援，并告知已按要求停止。完整退出会关闭远程救援，之后需要在电脑上重新开启。

升级维护期间不能通过飞书打断维护或另开业务。网络异常时会尝试发送连接故障提示；若电脑完全无网，只能在恢复后合并告知。电脑关机、休眠、断电，或守护本身无法恢复时，同机机器人无法保证通知，也不能用这条命令给电脑开机。

Windows 自动恢复需要原来使用机器人的 Windows 用户保持登录；锁屏可以，注销后不会继续救援。检查按周期进行，不是立即恢复；本机测试曾观察到约 1—3 分钟，但实际时间会随故障和电脑状态变化。连续恢复失败后会暂停自动重试，请到百宝箱查看状态和日志，并在本机排除故障后手动恢复。

其他帮助：

在“功能中心”点“剩余额度”，或直接发送“.查询剩余额度”，可查看每周额度和剩余重置卡；查看本身不会消耗重置卡。

发送“.使用说明”查看四页漫画课堂：注意事项、开始任务与指令、找到任务并图文续聊、监测通知与额度预警。发送“.文字版使用说明”再次查看本说明。

如果按钮或引用提示过期、对象不匹配，重新打开“功能中心”并查询目标任务，再从新消息操作。不要把旧列表的编号拿到另一份列表使用。
