# 通信守护与 Windows 自动恢复

本说明对应 v1.6.0。通信守护负责唯一飞书连接，业务进程负责会话与监测；Windows 计划任务仅检查守护健康，不建立第二条飞书连接。

## 启动、停止与完整退出

百宝箱服务行的“停止”保存业务停止意图，保留通信救援。刷新或重新打开百宝箱不会取消停止选择。通信守护在线时，绑定用户可在飞书私聊发送精确命令 `.启动飞书机器人`，无需引用旧消息。

托盘菜单“完整退出飞书守护（关闭远程救援）”会保存完整退出意图并关闭业务与守护，Windows 监督不会自动拉起。之后需在本机按“启动”重新开启。只退出百宝箱窗口不会退出守护。

只有守护健康、业务就绪且飞书连接在线，才表示启动成功。进程存在、命令已提交或按钮操作结束都不能代替就绪状态。维护模式禁止远程启动，升级结束按进入维护前的意图恢复。

## 新装和升级

新安装注册的恢复任务默认关闭，业务也不启动。完成自己的飞书应用设置、用户绑定及发送验收后，可在安装目录运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\installer\guardian-task.ps1 -Mode Enable -InstallRoot "<安装目录绝对路径>"
```

升级保留已有恢复任务的启用选择；旧版没有该任务时，只根据默认飞书服务原有自动启动或自动重启偏好迁移监督设置。旧偏好值保留，业务原来停止就继续停止，不因启用通信监督而启动业务；可以之后从百宝箱或飞书启动。无法证明旧业务正在运行时，不猜测为运行。

若本安装还存在旧的 `ProgressCheckingWX` 登录启动任务，安装器会核对当前用户和完整程序命令，只备份并停用确实属于本安装的任务，将原启用选择迁移到新监督。回滚恢复旧任务及原启用状态；属于其他安装或命令不匹配的同名任务不会被修改。新版自启入口不再注册直接启动业务的登录任务。

安装器会先暂停监督、进入维护并停止守护和业务，再备份与替换文件。失败回滚恢复程序、用户数据、计划任务及原意图。新装回滚移除本次任务；卸载关闭任务和救援，保留用户数据。已有守护状态的安装只支持原目录升级，不能直接搬到另一个目录。

## 恢复时机与限制

监督任务约每分钟检查一次，登录后另有一次延迟检查。崩溃需经过观察窗口；活进程无有效心跳需经过约 90 秒观察窗口，避免误杀初始化中的实例。加上调度周期，恢复通常需要数分钟，不能保证即时恢复。

恢复前由后端核对 PID、进程创建时间、实例记录、心跳和停止意图；身份不明或时钟异常时拒绝恢复。监督最多在 15 分钟窗口内尝试 3 次，并采用 60、180、600 秒退避；达到上限后暂停自动恢复。持续健康两分钟可清理未熔断的临时次数，已熔断状态需要明确手动解除。

计划任务使用当前 Windows 用户的 InteractiveToken，不保存密码、不提权，DPAPI 保持同一身份。锁屏但仍登录时可以运行；注销后不能运行。电脑断电、关机、休眠或网络不可用时不能保证接收启动命令或即时通知。此功能不提供远程开机。

任务主体行为依据 [Microsoft InteractiveToken 文档](https://learn.microsoft.com/en-us/windows/win32/taskschd/principal-logontype)；重复运行采用 [IgnoreNew 设置](https://learn.microsoft.com/en-us/windows/win32/taskschd/tasksettings-multipleinstances)，另有本地锁防止并发监督。

## 查看与解除恢复暂停

百宝箱状态显示守护、业务、飞书连接及可用的 Windows 监督信息。若显示自动恢复已暂停，请先检查日志，处理导致反复失败的原因，再运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\installer\guardian-task.ps1 -Mode Status -InstallRoot "<安装目录绝对路径>"
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\installer\guardian-task.ps1 -Mode ResetCircuit -InstallRoot "<安装目录绝对路径>"
```

解除恢复暂停只重置 Windows 监督次数，不改变业务停止、维护或完整退出意图，也不会直接启动业务。普通“启动”不会自动清空监督熔断。

监督状态与脱敏日志在配置数据库父目录的 `guardian` 子目录内：`windows-supervisor.json` 与 `windows-supervisor*.jsonl`。日志只记录时间、恢复事件、次数和错误代码，最多保留约 3 MiB；不要把整个配置、状态库或其他业务日志直接公开。恢复通知由通信守护合并和持久去重，Windows 监督不单独发送通知。
