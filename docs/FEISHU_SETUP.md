# 飞书企业自建应用设置

## 1. 创建应用

登录飞书开放平台开发者后台，在自己的企业或团队下创建“企业自建应用”，然后添加“机器人”能力。本项目不使用群自定义机器人 Webhook。

建议先只给自己使用；后台固定拒绝群聊和未绑定用户。

## 2. 最小权限

只申请：

| 权限 | 用途 |
|---|---|
| `im:message:send_as_bot` | 主动发送进度、审批和测试消息 |
| `im:message.p2p_msg:readonly` | 接收一对一消息事件 |
| `im:message:readonly` | 下载用户消息中的原图 |
| `im:resource` | 上传并发送可预览图片 |

不要申请通讯录、群管理、文件盘或其他无关权限。

## 3. 长连接、卡片回调与功能中心

在事件与回调页面完成以下配置，无需公网域名、回调 URL 或端口映射：

- 事件配置：选择“使用长连接接收事件”，订阅 `im.message.receive_v1` 和 `application.bot.menu_v6`。
- 回调配置：选择“使用长连接接收回调”，添加 `card.action.trigger`，不要选择 `card.action.trigger_v1`。
- 机器人自定义菜单：添加事件类型菜单项，名称“功能中心”，事件键 `progress_wx_feature_center`。事件订阅与菜单项事件键需分别配置。

若平台要求先检测连接才可保存，在下面本机向导的绑定阶段建立连接后返回平台完成配置与发布，再继续绑定。无需提前启用正式通知后台。

## 4. 发布

创建应用版本、提交并在企业内发布。新增权限或事件后也必须重新发布版本。

## 5. 启动一次本机统一向导

以下第5至7节都在同一向导内连续完成，不需要分别启动配置、绑定和测试脚本，也不需要每节结束后回到 Codex 再确认。仅按向导完成必要输入和实际确认。

打开 TreasureChest → 工具箱 → “飞书进度通知首次设置”。App ID 与 App Secret 从开放平台凭证页取得。App Secret 只在本机隐藏输入框输入，DPAPI 加密后保存；不要粘贴到 Codex、Issue、截图或命令行。

## 6. 绑定唯一用户

向导显示一次性代码后，用自己的飞书账号给机器人发送该代码。后台只接受 p2p、非机器人、精确代码消息，并只保存该账号的 open_id 白名单。代码短时有效且只能使用一次。

## 7. 测试与启动

先发送测试消息，确认手机收到；再建立历史基线并启动服务。用 TreasureChest 查看后台状态和监测列表。若图片失败，先确认 `im:message:readonly` 和 `im:resource` 已加入并发布新版本。

最后重新打开机器人私聊，确认底部“功能中心”可见并可打开新卡片，检查卡片按钮及表单响应。底部入口缺失时检查菜单项、事件订阅、应用发布与可用范围；按钮无响应时检查卡片回调。未配置底部菜单时可发送“.功能中心”打开入口。

当前四页图解位于 `components\codex-feishu\docs\assets\feishu-usage-classroom-20260908`，也可在机器人中发送“.使用说明”。


卡片按钮和表单还需在回调配置中订阅 card.action.trigger。底部菜单需要 application.bot.menu_v6 事件及 progress_wx_feature_center 菜单键，见 [详细设置](FEISHU_UPGRADE_PERMISSIONS.md)。
