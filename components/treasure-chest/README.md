# 百宝箱使用说明

百宝箱用于管理飞书后台服务、Codex 任务监测、常用工具和整套生态更新。

双击安装目录中的百宝箱快捷方式或 TreasureChest.exe。标题栏最小化按钮把窗口收至任务栏；关闭按钮把程序收至托盘。需要完全退出时，在托盘菜单选择退出。设置中的“自动启动时进入托盘”单独控制登录启动时的显示方式。

## 监测和后台服务

打开项目监测管理，可查看全部会话、长期监测与临时监测。加入长期监测后，任务不会按临时监测规则自动到期；移除监测不会删除或关闭 Codex 任务。精确项目搜索与模糊搜索不能同时启用。模糊搜索可以使用名称、描述或活动时间线索；扩大搜索范围前会提示，需自行选择。取消搜索会停止本次查询流程。

在后台服务区域可启动、停止、刷新或编辑服务。默认飞书服务显示为“指令使用（飞书）”，自己的服务名称会保留。删除管理条目不会删除外部程序。

## 通信守护与远程救援（v1.6.0）

飞书服务的“启动”“停止”统一交给通信守护处理。“停止”只停止业务，保存你的停止选择，通信守护继续接收远程救援；百宝箱不会因为刷新、重新打开或旧的自动重启选项而把业务重新拉起。其他普通后台服务仍使用各自的自启和重启设置。

状态说明分别显示通信守护、飞书连接和业务状态。出现进程并不等于启动成功：只有守护健康、业务就绪并且飞书连接在线，才显示运行中。命令超时或状态读取失败时，请刷新并查看日志，不要把按钮操作完成当成服务已经恢复。

守护在线时，可在已绑定的飞书私聊发送精确命令 `.启动飞书机器人`，不需要引用旧消息。主机关机、断网或通信守护不可用时无法接收该命令。Windows 恢复监督由安装配置负责，百宝箱不自行注册恢复任务。

如果状态显示“Windows 自动恢复已暂停（熔断）”，请先检查恢复日志，再按安装维护说明手动解除熔断。百宝箱会显示可用的恢复次数、错误和下次检查时间，但不会自动重置恢复次数或重新启动。普通“启动”也不等于解除 Windows 恢复熔断。

仅退出百宝箱不会退出通信守护。确实要关闭远程救援时，在托盘菜单选择“完整退出飞书守护（关闭远程救援）”并确认：这会停止业务和守护，保存完整退出意图，Windows 不应自动拉起。之后需要在本机重新启动；普通暂停业务请使用服务行的“停止”。维护期间禁止远程启动，维护结束按进入前的意图恢复。

控制操作记录保存在百宝箱 `logs/TreasureChest.log`；详细故障与恢复记录见后端的守护日志。分享前按隐私说明处理日志，不要公开配置、密钥和运行状态目录。本节功能须搭配支持 guardian 协议的新后端，旧后端会明确提示状态不可用，不会退回旧启动命令。

## 额度预警与记录

点击后台服务工具栏的“预警记录”，或双击 Codex 重置预警行，查看保存的完整提醒。按钮括号显示未读数，超过九条显示“9+”。打开记录不会自动标为已读；需要点击“将本次显示的记录标为已读”。过期记录仍可回看。

预警介绍的是官方额度重置消息及其适用条件，收到提醒不等于个人账户额度已经重置。来源不完整、来源读取失败或服务停止时，应查看状态说明；这些状态本身不表示发生了重置。Windows 接受托盘提醒也不保证提醒已经在屏幕显示，请同时查看预警记录。

## 设置与工具

设置中可调整主题、刷新间隔、系统托盘通知、登录自动启动及自动检查更新。工具箱可添加程序、脚本、快捷方式或目录。插件通过插件中心扫描；分享安装目录前，应检查自定义工具、插件和配置中的私人内容。

## 从旧版更新

v1.5.0 用户第一次升级须下载 v1.6.0 升级包，使用包内 `快捷升级.cmd`，详见[升级说明](../../UPGRADE.md)；旧版没有生态更新入口。升级完成后，以后的正式更新可在设置的“生态更新”中点击“立即检查更新”，阅读版本说明并决定是否下载安装。下载完成后会校验安装包，再由独立更新器完成升级并重新打开百宝箱。请保留完整安装目录，不要只复制主程序替换旧版。

通过正式安装器安装的受管理目录支持原地更新；开发源码目录或缺少安装记录的目录会禁止自动覆盖。若提示当前不是受管理安装，按该版本安装包附带的迁移说明操作。

升级可能需要更新飞书应用权限。以新版本附带的权限增量说明为准，在飞书开放平台完成必要授权后再测试相关功能。百宝箱不会代替管理员批准应用权限。

检查更新只使用正式 Release，忽略草稿和预发布版本。v1.6.0 的隔离安装、升级与失败回滚验证已通过；真实账号和桌面环境仍需按安装说明验收。
