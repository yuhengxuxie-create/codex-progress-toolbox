# FeiShuBOT 文字版使用说明

版本：1.5.0
更新日期：2026-08-27

重要提醒：

需要选择项目、会话、页码或监测任务时，一定要引用回复对应的机器人消息。不要把操作指令单独发送，否则机器人不知道你正在操作哪一份列表。

手机上的操作方法：长按机器人消息，点击“回复”，确认输入框上方出现引用内容，再输入指令并发送。

收到新建表单后，复制整段，然后只在冒号后面填上想要的内容就可以了哦。冒号前面的文字不要修改，提示词可以写多行。

当 Codex 在电脑端或飞书新建的任何会话中申请权限时，机器人都会发送“待审批”通知。引用这条通知，回复“A”或“允许一次”可只批准本次；回复“D”或“拒绝”可拒绝。只有 Codex 明确给出可安全复用的命令规则时，通知里才会出现“S”或“允许类似操作”，批准后同类命令以后可以直接执行。机器人不会自行猜测放行范围。

查看会话：

查看项目会话
第1步：在聊天框直接发送“查询项目列表”。
第2步：引用项目列表，发送“展开A01”。
第3步：引用项目里的会话列表，发送“选定a01”。

查看个人会话
第1步：在聊天框直接发送“查询个人会话”。
第2步：引用个人会话列表，发送“选定p01”。

需要翻页时，引用当前列表发送“第2页”。A01、a01、p01 都是机器人当次列表里显示的编号，请按实际编号填写。

新建对话：

新建项目
在聊天框直接发送“新建项目”。收到表单后引用回复，填写项目名称、是否需要第一段会话（只能填“是”或“否”）以及首轮对话提示词。

新建个人会话
在聊天框直接发送“新建个人会话”。收到表单后引用回复，在“首轮对话提示词：”后填写你的要求。

在已有项目中新增会话
先发送“查询项目列表”，然后引用项目列表发送“新建项目会话”。收到表单后填写项目编号和首轮对话提示词。

继续已有对话：

按“查看会话”的步骤选定目标后，机器人会发送会话概览。引用这条概览，直接输入你的新要求并发送，内容就会进入原来的 Codex 会话，不会新建任务。

如果概览下方带有生成图片，也可以直接引用图片提出修改要求。

发送图片：

推荐方法
引用目标会话的进度通知或会话概览，在同一条消息里同时放入图片和文字说明，然后发送。机器人会把图片和文字一起交给正确的 Codex 会话。

备用方法
如果手机无法把图片和文字合并发送，可以先引用机器人消息只发图片。收到“图片已暂存”后，直接发送一条普通文字说明，不要再引用其他消息。暂存有效期为10分钟，最多5张。

只想发送图片时，发送“.发送”；放弃本次暂存时，发送“.取消”。

机器人返回的生成图片会直接显示在聊天中，不需要先下载文件。引用图片即可继续提出修改要求。

管理进度监测：

查看监测任务
在聊天框直接发送“查询监测列表”。

添加永久监测
引用项目会话列表发送“添加监测a01”，或引用个人会话列表发送“添加监测p01”。已经打开会话概览时，也可以直接引用概览发送“添加监测”。

移除监测
引用监测列表发送“移除m01”。已经打开会话概览时，也可以引用概览发送“移除监测”。明确移除后，系统不会擅自恢复。

新建或最近活跃的顶层任务会自动监测，连续24小时没有活动后自动到期；手动添加的监测永久有效。任务需要你选择路线、审批或补充信息时，机器人会立即通知。

其他帮助：

在聊天框直接发送“查询剩余额度”，可以查看 Codex 每周剩余额度和剩余重置卡数量。这个命令不需要引用机器人消息，也不会消耗重置卡。

发送“使用说明”可以查看六页漫画课堂。发送“文字版使用说明”可以再次查看本说明。

如果机器人提示上下文不匹配，请重新发送最开始的查询命令，取得一份新的列表后再操作。
